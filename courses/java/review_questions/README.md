## 后续出题约定

- 避免重复询问正文已经明确列出、并在运行结果中直接观察过的简单事实。
- 根据章节内容使用理论题、编程题或两者混合；理论题不能有效检验理解时，优先改为代码分析、调试或实现题。
- 编程题通常聚焦 1～3 个函数或约 10～40 行核心代码，既不只写一两行，也不扩张成新的完整章节。
- Java `00-foundation` 仍不自动创建复习题，除非学习者主动提出。
