## 学习约定

- 正式章节按模块内的依赖顺序推进；不同模块之间也会明确说明所复用的旧知识。
- 遇到会阻碍当前内容的前置知识时，直接插入一章 `00` 基础知识，再返回当前正式章节。
- 基础知识章只讲解和演示，不自动生成复习题；需要练习时由学习者主动提出。
- 每个正式章节安排约 4～6 个递进实现检查点，并至少包含一个多方法或多对象协作的综合任务。
- 复习题避免重复简单事实；理论题不合适时使用适量编程题或混合题。
