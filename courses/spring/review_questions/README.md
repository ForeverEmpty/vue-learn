## 出题约定

- 测试代码继续作为自动验收工具，用来确认练习行为是否正确。
- 后续复习题不考 JUnit、MockMvc、测试分类、测试注解或断言 API。
- 不要求学习者编写测试，除非之后主动提出要学习测试。
- 如果某个测试概念直接影响生产代码理解，只在正文中用通俗语言说明，不把它设为复习题。
